# 链接迁移修订计划

用户已明确要求 SIZE 与相对链接一并调整，原话及新旧冻结契约由受控更新记录在 spec.md 的 CONTRACT_DECISIONS 中。此次授权优先于旧组计划；不修改其他所有者卡片。

1. 预检全部卡片，建立旧文件路径至新 spec.md 的完整映射。以 CommonMark 解析器识别真正链接、图片及引用定义，按引用源与目标的新旧位置调整地址，保留正文其他字节、查询和片段。不扫描仓库其他文件。
2. 将所有相互依赖的形态与正文变更放入同一持久迁移记录，恢复使用已登记映射与前后内容，不依据半迁移现场重算。保持 PM-001 的受管写入恢复。
3. 用真实目标覆盖双方迁移、已有目录反向引用、外部文件引用、图片、引用定义、代码示例、URL/锚点、编码及异常语法；验证中断恢复及重复 init 内容/mtime。
4. 同步发布规则与中文说明，保留原 PM/QA 原文并更新原作者处置。测试、提交推送、rebase 最新组基线后重验，回填 SHA 后 move review；审核、组集成由编排端负责。
