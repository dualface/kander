# kander version

Source: new in this file; the rule files did not describe this command beyond its syntax line

## Purpose and users

Prints the binary version. Used by the user and by scripts.

## Syntax

```text
kander version
```

## Arguments

None.

## Preconditions

None.

## Effects

Read-only.

## Output

`kander <version>` on standard output.

## Rejections

- Any argument is a usage error.
