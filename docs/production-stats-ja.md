## 集計の定義

- **完了カード**: `kanban/done/` 配下のカードディレクトリ数. `archived/` と `trash/` は含めない.
- **期間**: カード ID の日付プレフィックスによる最初と最後の日付. 両端を含む.
- **レビューバッチ**: `reviews/batches/<バッチ>/disposition.json`. バッチ ID で重複を除く. タスクグループの複数カードにまたがるバッチは各カードに保存されるが, 1 回として数える.
- **レビュー実行**: 1 つのレビュー役割 (PMQA / Security など) による 1 回のレビュー. run ID で重複を除く.
- **ブロックされたバッチ**: バッチ内のいずれかのレビュー実行がブロッキング指摘を報告した.
- **ブロッキング指摘**: レビュー報告の `FINDINGS` の項目 (blocking / high / medium の 3 段階). 非ブロッキングの提案は含めない.
- **実行したカード**: カードヘッダーの `OWNER` フィールド. 2026-09 以降の新形式カードのみが持つ: 878 枚.
- **カード数はスループットであり, 価値や難易度ではない.** プロジェクトごとにタスクの大きさが異なるため, 横比較には向かない.
